# Chía Mora — Energía natural en cada cucharada

## Descripción

**Chía Mora** es una página web creada para presentar un proyecto escolar relacionado con un producto elaborado a base de chía y mora.

La página muestra información del proyecto de forma visual y organizada, incluyendo sus beneficios, ingredientes, preparación y presentaciones.

## Contenido de la página

- **Inicio:** presentación del proyecto Chía Mora.
- **Beneficios:** información sobre los beneficios del producto.
- **Ingredientes:** ingredientes utilizados para su elaboración.
- **Preparación:** explicación del proceso de preparación.
- **Presentaciones:** información sobre las formas de presentación del producto.
